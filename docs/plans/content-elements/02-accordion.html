HTML/CSS-only accordion for Froala / Nextlot

Same sl-ce library as tabs. Authors paste HTML into Froala. No JavaScript. Visuals mirror RapidRailsUI accordion variants with StockLive navy and terracotta. Primary: --bordered.

status: shipped · rev 2 · 2026-07-31 · namespace: sl-ce · spec: plans/content-elements/02-accordion.md

Approach: native <details> / <summary>. Multiple items may be open. Exclusive one-at-a-time needs radio or JS — out of scope. Single show-more → 05-expand.

1. Live preview

Click any header. Open more than one — state is independent per item and per group.

Interactive demo · Lot FAQ (bordered)

Overview

Bordered stack, navy titles, terracotta chevron when open. Panel padding includes top so content is not flush under the trigger.

Pedigree

Panels hold arbitrary HTML — lists, images, tables, traits.

Comments

Sale comments and vendor notes live here in real content.

ASBV / documents

Links to PDFs or inspection reports — still just HTML in the panel.

Separated variant

Bidding

Unlike tabs, opening items here does not reset other groups — no shared page :target.

Terms

Long-form conditions in the panel without changing other groups.

Why details: Accordion is disclosure. Native <details> gives keyboard support and multi-open state without JS. Tabs needed :target because they are a mutually exclusive panel switcher.

4. Limits (honest)

  • No exclusive (one-open) mode without radio/JS.
  • No Lucide icons / subtitles in v1 header — keep Froala markup minimal.
  • Froala must allowlist details, summary, open, aria-hidden.
