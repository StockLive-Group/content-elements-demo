# Content Elements demo

Public preview of StockLive **Content Elements** (`sl-ce`) — starting with CSS-only tabs in a lot listing context.

**Live:** https://stocklive-group.github.io/content-elements-demo/

## What this shows

- Lot row layout (image left, description right)
- `sl-ce-tabs` using `:target` + `:has()` (no JavaScript)
- Placeholder for future content elements in the description column
