# Content Elements demo

Public preview of StockLive **Content Elements** (`sl-ce`) — CSS-only components in a lot listing context.

**Live:** https://stocklive-group.github.io/content-elements-demo/

| Demo | Page |
|------|------|
| Tabs | [index.html](https://stocklive-group.github.io/content-elements-demo/) |
| Accordion | [accordion.html](https://stocklive-group.github.io/content-elements-demo/accordion.html) |

## What this shows

- Lot row layout (image left, description right)
- `sl-ce-tabs` using `:target` + `:has()` (no JavaScript)
- `sl-ce-accordion` using native `<details>` / `<summary>` (no JavaScript)
- StockLive brand tokens (navy / terracotta); accordion visuals aligned with RapidRailsUI bordered
